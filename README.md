## 🚀 Sobre el Proyecto

Este es mi portafolio personal donde comparto mis proyectos de desarrollo, habilidades técnicas y experiencia profesional. Está diseñado para ser minimalista, rápido y totalmente responsive.

## 🛠 Tecnologías Utilizadas

Este proyecto fue construido con el stack:

- **Frontend:** React.js & React-Bootstrap
- **Estilos:** CSS3 & Framer Motion
- **Entorno:** Docker & Docker Compose
- **Despliegue:** Vercel / Nginx

## ✨ Características

- **📖 Diseño Multi-página:** Navegación fluida con React Router.
- **🐳 Dockerized:** Configuración lista para desarrollo y producción.
- **📱 Responsividad Total:** Optimizado para móviles, tablets y escritorio.
- **🎨 Fácil Personalización:** Estructura de componentes modular.
- **💻🌐 Proyecto en vivo:** https://extorresl.github.io/My-Portfolio/
- **🕵🏼 Basado en el proyecto original de:** [Soumyajit Behera](https://github.com/soumyajit4419/Portfolio).
